# English translation style — Türkçe Akademi

Read `i18n-src/TRANSLATION-RULES.md` first.

Audience: English-speaking adults learning Turkish. Use natural, modern English (British spelling is fine, but be consistent: *grammar*, *pronunciation*, *practise* as a verb). Keep the friendly, factual tone of the French site.

## Style notes

- Translate `tu`/`toi` as “you” naturally; translate `vous` as “you” and, when the distinction matters, say “formal you” or “polite you”.
- Use “Turkish” as the language name, not “Turkey Turkish”.
- Use the serial comma sparingly.
- Avoid literal renderings of French idioms; write what an English teacher would write.
- Keep Turkish suffixes in hyphenated form exactly as in the source (e.g. `-ler / -lar`).
- For Arabic script or Kazakh text embedded in source strings, preserve it unchanged.
